ПУБЛИКАЦИЯ ПОРТФОЛИО НА GITHUB PAGES
=====================================

Целевой адрес:
https://nexti123.github.io/

Файлы, которые должны лежать в корне репозитория Nexti123.github.io:
- index.html
- bro11m.py
- .nojekyll

Порядок публикации:
1. В GitHub создайте публичный репозиторий с точным именем:
   Nexti123.github.io
   Аккаунт: Nexti123
2. Загрузите index.html, bro11m.py и .nojekyll в корень репозитория.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку main и папку /(root), затем нажмите Save.
6. Подождите, пока GitHub Pages завершит публикацию, и откройте:
   https://nexti123.github.io/

Ссылка «Скачать bro11m.py» в index.html относительная, поэтому файл проекта должен
лежать в корне репозитория рядом с index.html.

ВАЖНО:
Подключённый GitHub-доступ позволил проверить список доступных репозиториев, но
репозиторий Nexti123.github.io пока не найден. Доступный инструмент интеграции
не предоставляет создание нового репозитория, поэтому создать его нужно в интерфейсе
GitHub. После этого загрузите эти подготовленные файлы. Сам адрес станет доступен
после включения GitHub Pages и завершения публикации.

Сайт статический, работает на телефонах и компьютерах. Сертификаты пока представлены
карточками-заглушками; контактные данные не добавлены.
