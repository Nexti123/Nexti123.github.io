КАК ОБНОВИТЬ САЙТ НА GITHUB PAGES

1. Откройте репозиторий https://github.com/Nexti123/Nexti123.github.io
2. Нажмите Add file -> Upload files.
3. На компьютере распакуйте этот архив (site_for_github_pages.zip).
4. Перетащите на GitHub файлы из папки сайта: index.html, .nojekyll и bro11m-project.zip.
   Если GitHub спросит про существующий index.html, загрузка должна заменить его через Commit changes.
5. Нажмите Commit changes внизу страницы.
6. Подождите несколько минут и обновите https://nexti123.github.io/

Файл bro11m-project.zip содержит папку проекта, файл main.py и README с инструкцией по запуску.
Карточки сертификатов пока пустые — туда можно добавить свои реальные документы позже.
